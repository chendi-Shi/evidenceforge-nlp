# v3 实测结果：蒸馏中的源任务收益与迁移退化

**这轮实验支持“表示保持项缓解了当前配置下的负迁移”，没有证明训练后的模型超过冻结原模型。** 在 BEIR SCIDOCS 全量 25,657 篇文档、1,000 条测试查询上，`kd_anchor` 的三种子平均 nDCG@10 为 **0.215630**，比 `kd` 的 0.209372 高 **0.006258**（相对 +2.99%），仍低于 frozen base 的 **0.216406**。三个种子的主比较配对查询区间均大于 0；这不等于跨训练随机性的总体显著性，也不能改写成“泛化能力超过原模型”。

全部 **4 组 × 3 种子 × 750 步 = 9,000 次有效梯度更新**已完成。每组实际训练到 750 步，再按源验证排名选定权重；选中较早 checkpoint 不代表提前停止训练。公开 [原始报告](../results/distillation/report.json)、[独立复算](../results/distillation/independent_audit.json)、[次要分析](../results/distillation/analysis.json) 和 [案例明细](../results/distillation/failure_cases.json)。下文数字保留六位小数，完整精度以 JSON 为准。

## 评测对象和对照

教师为固定版本 Qwen3-Embedding-0.6B Q8_0；学生为 MiniLM，冻结词嵌入及前四层，更新后两层的 **3,548,928 个参数**。训练仅使用本机 CPU，教师推理使用本机 Iris Xe/Vulkan，没有付费 API 或云 GPU。`ce` 为监督交叉熵；`kd` 为 CE 加教师分数分布 KL；`anchor` 为 CE 加原始表示的余弦距离保持项；`kd_anchor` 同时使用这两项。具体损失、固定权重、输入长度和预先封存的实现见 [实验说明](DISTILLATION.zh-CN.md) 与 [协议](../results/distillation/protocol.json)。

源数据是固定 MS MARCO 三元组来源的 12,000 条训练查询和 1,000 条验证查询。源验证搜索同一个 **1,997 篇文档池**，用于比较 250/500/750 步 checkpoint；**不是 MS MARCO 全库官方成绩**。SCIDOCS 只评测选定后的学生及 base，排除查询与文档 ID 相同的条目。没有测得 Qwen 在 SCIDOCS 上的质量，不能据此声称学生保留了教师多少比例的性能。

| 模型 | nDCG@10 | MRR@10 | Recall@10 | Recall@50 |

## 主比较与次要交互

主比较预先指定为 `kd_anchor − kd` 的 nDCG@10。每个 seed 内独立对 1,000 条查询进行 **2,000 次配对 bootstrap**，抽样 seed 为 42。没有把 3×1,000 个 seed/query 组合当成独立样本。

| 训练 seed | 主差值 | 95% 配对查询区间 |
| --- | ---: | --- |
| 17 | +0.007120 | [+0.003196, +0.011209] |
| 42 | +0.005357 | [+0.001048, +0.009643] |
| 73 | +0.006297 | [+0.002233, +0.010232] |

跨种子的差值均值为 **+0.006258 ± 0.000882 SD**。这些查询区间条件于已经训练好的模型，不衡量训练随机性；没有相关查询聚类或多重比较校正。只有三个训练顺序种子，且共享预训练初始化、关闭 dropout，不能解释为覆盖了所有训练不确定性。

次要交互为 `(kd_anchor − kd) − (anchor − ce)`，检验保持项在 KD 条件下的影响是否不同于普通 CE 条件。仅观察主比较为正不足以证明二者协同：

| 训练 seed | 交互差值 | 95% 配对查询区间 | KD + anchor − base 的区间 |
| --- | ---: | --- | --- |
| 17 | −0.005486 | [−0.011121, +0.000154] | [−0.002996, +0.001139] |
| 42 | −0.000373 | [−0.005836, +0.004931] | [−0.003384, +0.001013] |
| 73 | +0.001840 | [−0.003036, +0.006824] | [−0.002381, +0.001943] |

交互均值 **−0.001340 ± 0.003757 SD**，三个区间均跨 0，不支持稳定正交互结论。组合相对 base 的区间也都跨 0，**这不能证明等效、无损保持或非劣性**；实验没有预设等效界值。次要分析采用独立的 Python 随机抽样实现，主比较使用原报告及独立审计核对过的 NumPy 抽样，有限次抽样的区间端点不要求逐位一致。

## 源验证收益和表示漂移的取舍

冻结 base 的源验证 nDCG@10 为 **0.887126**。四组源验证都改善，但没有转化成高于 base 的目标均值。这体现了本次源训练目标与目标引用检索任务之间的取舍。

| 模型 | 所选 checkpoint 的源 nDCG@10（均值 ± SD） | 相对源 base | 所选步数（17 / 42 / 73） | 所选查询漂移均值 | 所选文档漂移均值 |
| --- | ---: | ---: | --- | ---: | ---: |
| CE | 0.922995 ± 0.002040 | +0.035870 | 500 / 250 / 250 | 0.034914 | 0.119001 |
| KD | 0.910478 ± 0.001788 | +0.023352 | 750 / 750 / 750 | 0.220080 | 0.252423 |
| anchor | 0.925700 ± 0.000284 | +0.038574 | 750 / 750 / 500 | 0.004096 | 0.010914 |
| KD + anchor | 0.898562 ± 0.001343 | +0.011437 | 500 / 750 / 750 | 0.002791 | 0.005739 |

漂移定义为相对原模型向量的平均余弦距离，只在**源验证查询/文档**上测量，越小表示相对原始表示变化越小。不同组选中步数不同，因此还要比较相同步数。下表均为三 seed 平均；每个 seed 的四组 250/500/750 步轨迹均保存在 [analysis.json](../results/distillation/analysis.json) 的 `per_seed.*.arms.*.source_validation.validation_trajectory`。

| 步数 | 模型 | 源 nDCG@10 | 查询漂移 | 文档漂移 |
| --- | --- | ---: | ---: | ---: |
| 250 | KD | 0.893763 | 0.116775 | 0.134387 |
| 250 | KD + anchor | 0.891419 | 0.002112 | 0.004174 |
| 500 | KD | 0.908065 | 0.199163 | 0.227945 |
| 500 | KD + anchor | 0.896550 | 0.002546 | 0.005129 |
| 750 | KD | 0.910478 | 0.220080 | 0.252423 |
| 750 | KD + anchor | 0.898106 | 0.003005 | 0.006020 |
| 750 | CE | 0.921197 | 0.088903 | 0.224835 |
| 750 | anchor | 0.925546 | 0.003919 | 0.010681 |

即使对齐步数，保持项对应的源表示变化仍更小，所以这个观察不能完全由较早选模解释。但组合的源排名收益也低于 KD，符合“限制表示变化同时限制源适应”的取舍。这里没有目标表示漂移测量，不能进一步声称证明了 SCIDOCS 几何结构保持或确定了退化原因；也没有重新用目标分数挑选 checkpoint。

## 可核查的改善与失败案例

以下是**结果出来后的描述性极端选例**。先对每个查询计算三个 seed 的配对 nDCG@10 差值均值，分别对 `kd_anchor − kd` 和 `kd_anchor − base` 排序，保留最大改善和最大退化各两例；同差值按 query ID 排序。JSON 保留全部八条选例，下文取每个比较的两端各第一条，共四例。它们不是随机或代表性样本，不能用于证明普遍机制。

按同一逐查询平均差定义，全 1,000 条查询中，组合相对 KD 为 **305 胜 / 457 平 / 238 负**；相对 base 为 **194 胜 / 605 平 / 201 负**。平局容差为 `1e-12`。这些计数没有把 seed 当成额外查询。

| 案例与 query ID | base nDCG | KD 三 seed 均值 | KD + anchor 三 seed 均值 | 选例比较差值 |
| --- | ---: | ---: | ---: | ---: |
| 数字取证流程；`bd034b87414c58fc731c193fdd37f59b3db883fa` | 0.629552 | 0.186585 | 0.590959 | 对 KD +0.404374 |
| 工业三维对象识别数据集；`2094f315289ccf9b676e0790fb3dd1bc4acad98c` | 0.000000 | 0.371840 | 0.107381 | 对 KD −0.264459 |
| DeepMimic 动作技能；`1b9ce6abc0f3024b88fcd4dbd0c10cf5bcf7d38d` | 0.213986 | 0.345191 | 0.406449 | 对 base +0.192463 |
| 主题标签与相似哈希；`44a56dc083e3e2b07f11aae29c1ee560f46efa4a` | 0.233302 | 0.032680 | 0.065360 | 对 base −0.167943 |

**改善不等于超过原模型。** 数字取证查询中，相关文档 `28605ab2a9444c8fbe37982fb4005c82b60003f2` 在 base 为第 3，KD 的三个 seed 为 **47 / >50 / >50**，组合为 **5 / 4 / 5**。组合显著恢复了这篇文档的位置，但该查询的组合 nDCG 均值仍低于 base，直接体现“缓解损失”和“取得新增收益”的区别。

**保持也可能丢掉适应带来的局部收益。** 工业三维对象识别查询中，相关的无纹理物体姿态数据集文档 `dbd66f601b325404ff3cdd7b9a1a282b2da26445` 在 base 为第 11，KD 三个 seed 均为第 1，组合降至 **9 / 7 / 8**。组合仍比 base 更早找到它，但没有保留 KD 在这个查询上的完整收益。这是排名现象；不能仅靠该例证明保持损失的因果机制。

**存在超过 base 的局部成功。** DeepMimic 查询中，相关动作控制文档 `9917363277c783a01bff32af1c27fc9b373ad55d` 从 base 第 12 进入组合的 **8 / 7 / 8**；另一相关文档 `de9b0f81505e536446bfb6a11281d4af7aa1d904` 从 base 第 2 变为组合的 **2 / 1 / 1**。这解释了该查询 nDCG 的提升，但不能抵消其他查询的退化而宣称总体超过 base。

**与查询主题贴近的相关文档仍会下滑。** 主题标签查询中，相关文档 `682988d3cc614c122745d0e87ad9df0f44c3e432` 从 base 第 5 降到组合的 **11 / 10 / 10**，另一文档 `99f231f29d8bbd410bb3edc096a502b1ebda8526` 从第 9 降到 **15 / 13 / 13**。前 10 名边界使这些小幅位置变化明显影响 nDCG；组合并未消除排名退化。

每个案例的全部已标注相关文档 ID、三个 seed 的 nDCG 和文档排名均见 [failure_cases.json](../results/distillation/failure_cases.json)。`null`/`>50` 仅表示未进入保存的前 50，无法由此知道精确全库排名。案例说明是对本地已授权文本和排名的概括，不重新分发查询/文档全文；引用检索标签也不等于穷尽的语义相关性判断。

## 复算与边界

[独立审计脚本](../scripts/audit_distillation.py) 已从 13 份 TREC 与 qrels 复算全部指标及三个 seed 的主比较区间，并核验训练完成、选模与权重哈希；[已保存审计结果](../results/distillation/independent_audit.json) 为 `passed`。这些核对建立保存产物的一致性，不独立认证历史运行时间，也不重新执行模型推理。

```powershell
.\.venv\Scripts\python.exe scripts/audit_distillation.py --check
.\.venv\Scripts\python.exe scripts/analyze_distillation_results.py
.\.venv\Scripts\python.exe scripts/analyze_distillation_failures.py
# 显式保存到新文件；已有产物拒绝覆盖。
.\.venv\Scripts\python.exe scripts/analyze_distillation_failures.py --output results/distillation/failure_cases.rerun.json
```

[案例脚本](../scripts/analyze_distillation_failures.py) 仅用标准库，先确认完整评测与通过审计，再核对目标文件哈希、七份相关排名和逐查询指标。它不加载模型、不调参、不改协议；[五项合成边界测试](../tests/test_distillation_failures.py) 覆盖双向选例与排序、缺失 seed、分数篡改、禁止输出全文和已有文件拒绝覆盖。测试通过只证明这些程序行为，不是模型质量证据。

本轮仍是经典数据集和既有损失的受控实验：固定的少量源训练数据、静态上游 BM25 负例、单一新目标集、三个训练顺序 seed，以及没有专门调优的固定损失权重，限制了外推范围。源验证有文档交叠、潜在语义重复和不完整正例；目标是 BEIR 的引用检索子任务，不是原 SciDocs 全套评测。教师与学生的 token 上限不同，不能把观察完全归因为参数规模。完整数据来源与许可见 [实验说明](DISTILLATION.zh-CN.md#来源与使用范围)；项目代码许可证不改变数据许可。

可以据此展示的能力是：设计并执行可复核对照，完成本地蒸馏与表示保持训练，分别报告源收益、目标负迁移、随机性和失败案例。当前证据不足以支持“新算法”“SOTA”“全面超过原模型”或“无损迁移”的表述。
