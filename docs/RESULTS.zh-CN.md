# EvidenceForge v1 混合检索结果与误差分析

本文保留 v1 的完整结果。v2 三组 LoRA、未适配对照和 NFCorpus 迁移结果见[神经适配报告](ADAPTATION_RESULTS.zh-CN.md)；两个版本的输入长度、精度和监督预算不同，不应把其差异单独归因于适配训练。

2026-10-13 的完整 CPU 实验中，LambdaMART 重排在 BEIR SciFact **300 条公开测试查询**上的 nDCG@10 为 **0.7149**，高于 RRF 的 **0.6870**，绝对增加 **0.0279**，相对增加 **4.06%**。这是固定公开基准上的检索结果，不能解释为论断核验准确率或真实业务收益。

数值来自 [report.json](../results/scifact/report.json)，模型选择记录来自 [frozen_models.json](../results/scifact/frozen_models.json)。以下小数做了四舍五入，原始报告保留完整精度。

## 完整测试集对照

各方法使用相同的 5,183 篇摘要、300 个查询与官方相关性标注；指标按查询取宏平均。重排和消融使用相同的 RRF top 50 候选，测试阶段不注入相关文档。

| 方法 | nDCG@10 | MRR@10 | Recall@10 | Recall@50 |
| --- | ---: | ---: | ---: | ---: |
| BM25 | 0.6634 | 0.6309 | 0.7876 | 0.8704 |
| 冻结 MiniLM Dense | 0.6426 | 0.6009 | 0.7806 | 0.8887 |
| RRF | 0.6870 | 0.6504 | 0.8182 | 0.9447 |
| **RRF + LambdaMART** | **0.7149** | **0.6741** | **0.8549** | **0.9447** |
| 相同候选 + 词面特征重排 | 0.6728 | 0.6378 | 0.8074 | 0.9447 |

这组结果支持三个具体观察：Dense 单路的 nDCG 低于 BM25，神经模型没有自动胜出；RRF 在本次实验中改善了两路基线的排序与候选召回；完整特征重排进一步改善头部排序，而仅保留词面特征的重排点估计低于 RRF。

相对 RRF，学习重排使 53 个查询的 nDCG@10 上升、28 个下降、219 个不变。这些计数来自 [per_query.jsonl](../results/scifact/per_query.jsonl)，不代表所有查询都受益。

## 差值区间与消融解释

采用同一批查询的配对 bootstrap，2,000 次有放回重采样，seed=42，报告 95% 分位数区间。单位均为指标原始数值，而非相对百分比。[完整差值记录](../results/scifact/report.json)

| 比较 | 指标 | 宏平均差值 | 95% 区间 |
| --- | --- | ---: | --- |
| 完整重排 − RRF | nDCG@10 | +0.0279 | [+0.0117, +0.0445] |
| 完整重排 − RRF | MRR@10 | +0.0237 | [+0.0060, +0.0407] |
| 完整重排 − RRF | Recall@10 | +0.0367 | [+0.0092, +0.0650] |
| 完整重排 − 词面特征重排 | nDCG@10 | +0.0421 | [+0.0227, +0.0628] |

区间在当前重采样设定下均为正，但查询并非完全独立，当前没有按论断组重采样、没有多重比较校正，也没有覆盖训练随机性的多次独立运行。因此，结论限定于本次数据与协议。

消融将 16 维特征中的 dense 分数、dense 倒数排名和 RRF 得分移除，使用剩余 13 维特征重新训练；两者候选池完全一致。它测量的是**重排阶段语义及融合特征的贡献**，不是从整个系统移除 Dense 的效果。

RRF 候选池的 oracle nDCG@10 为 **0.9461**，候选 Recall@50 为 **0.9447**；15 条查询的已标注相关文档全部未进入候选池。RRF、完整重排与消融的 Recall@50 相等，因为它们只改变同一批 50 篇文献的次序。Oracle 只用于判断还有多少排序空间，不参与模型推理。

## 验证集选择与训练记录

809 条官方训练查询按共享相关文档或规范化论断的连通关系形成 490 组，最大组含 8 条查询。seed=42 的内部划分为 **647 条训练、162 条验证**；内部两侧共享相关文档数和规范化论断数均为 0。[训练记录](../results/scifact/model/metadata.json)

| 内部验证方法 | nDCG@10 | 用途 |
| --- | ---: | --- |
| RRF | 0.767439 | 固定融合基线 |
| 完整特征重排 | 0.768087 | 按预定规则选择学习重排 |
| 词面特征重排 | 0.729333 | 消融的内部验证结果 |

完整重排的验证优势只有约 **0.00065**；没有据此声称验证集差异稳定或显著。两个重排模型均从 `{7,15}` 叶子的预定网格选择 7 叶，使用 100 轮、学习率 0.05、`min_child_samples=20`、`reg_lambda=1`，随后在全部 809 条训练查询上重训。

全量训练矩阵含 **40,512 个查询文档对**，即 `809 × 50 + 62`；62 个未自然召回的相关文档对只补入训练矩阵。内部验证和测试排名没有这种补入。模型与方法建议于北京时间 **14:10:07** 固定，之后才运行测试评估；建议规则是在内部验证上比较完整重排与 RRF，并非看过测试成绩后选择最高者。

## 三个可复查案例

下面是用于解释不同错误类型的定性案例，不是随机样本。查询与指标可在 [per_query.jsonl](../results/scifact/per_query.jsonl) 按 ID 查找；排名来自 [RRF run](../results/scifact/runs/rrf.trec)、[Dense run](../results/scifact/runs/dense.trec)、[BM25 run](../results/scifact/runs/bm25.trec) 与 [重排 run](../results/scifact/runs/learned.trec)。标题和摘要已同下载后的 `data/scifact/corpus.jsonl` 核对。

### Q1278：把池内相关文献从第 23 位提升到第 1 位

该查询论断声称，癌症患者接受 co-IR blockade 不会发生不良自身免疫事件。标注文献为 **11335781**，标题为 *Is autoimmunity the Achilles' heel of cancer immunotherapy?*

| 文献 11335781 的位置 | BM25 | Dense | RRF | 完整重排 | 词面特征重排 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 排名 | >50 | 1 | 23 | 1 | 3 |

其摘要讨论癌症免疫治疗的免疫毒性与自身免疫问题，但用词与查询不完全一致。Dense 已找到该文献，RRF 同时考虑两路排名后将它排到前十之外；学习重排重新提升它，nDCG@10 从 0 变为 1。这说明此例的改善发生在精排阶段，没有新增召回。

这里的“命中”尤其不能读成“论断为真”：查询含否定表述，摘要却在讨论免疫毒性。项目只判断检索相关性，没有输出支持或反驳标签。至于具体哪一维特征导致提升，当前未做单样本干预归因，不能仅从排名变化下结论。

### Q232：头部重排退化，并存在未标注文献的解释空间

该查询关注南苏丹失明的主要原因。标注文献 **10536636** 的标题为 *Prevalence and Causes of Blindness and Low Vision in Southern Sudan*，摘要明确说明研究旨在估计当地失明、低视力及其原因。

该文献由 **RRF 第 1 位降到重排第 2 位**，nDCG@10 从 **1.0000 降到 0.6309**，MRR@10 从 1 降到 0.5。重排第 1 位变为未在该查询 qrels 中标注的 **7655029**，*The Burden of Trachoma in Ayod County of Southern Sudan*。这条记录也在 [errors.json](../results/scifact/errors.json) 中归为 `regression_against_rrf`。

按基准标签，这是确定的排序退化；从文本主题看，竞争文献也与南苏丹沙眼相关。因此不能未经人工扩展标注就断言它完全无关，也不能为了让分数更好看而自行改动测试标签。此例同时暴露了学习重排的误差和稀疏相关性标注的局限。

### Q1175：相关文献未进候选，精排没有修复空间

原始查询是 “The PPR MDA5 has two N-terminal CARD domains.”，标注文献为 **31272411**，*Immune signaling by RIG-I-like receptors.*

它没有出现在 BM25、Dense 或 RRF 的 top 50 中，因此完整重排与消融也无法返回它，所有方法的 nDCG@10 和 Recall@50 均为 0，候选 oracle nDCG@10 也为 0。这条记录在 [errors.json](../results/scifact/errors.json) 中归为 `candidate_retrieval_miss`。

该摘要确实提到 MDA5 与 RIG-I-like receptors，但没有直接写出查询中的 N-terminal CARD domains 结构描述。摘要级词面和语义匹配未能把标注文献带入前 50，是已经观察到的失败；需要更大候选池、术语扩展或更完整文本来验证改进方向，单纯更换精排器不能找回池外文档。

## 已发现的重叠与后验敏感性检查

官方 train/test **query ID 重叠为 0**，但小写、去标点和数字归一化后的论断签名有 **6 个重叠**，涉及测试查询 `1292、13、1359、279、814、870`。内部组级划分没有改变这个官方 train/test 设置。因此，本项目没有使用 test 标签监督训练，并不等于官方划分完全不存在语义或文本变体重叠。[原始审计字段](../results/scifact/report.json)

为了观察这 6 条查询对汇总分数的影响，在已有逐查询结果上排除它们，对剩余 **294 条**重新取宏平均，得到：

| 方法 | 标准 300 条 nDCG@10 | 后验排除 6 条后的 nDCG@10 |
| --- | ---: | ---: |
| BM25 | 0.6634 | 0.6634 |
| Dense | 0.6426 | 0.6421 |
| RRF | 0.6870 | 0.6874 |
| 完整重排 | 0.7149 | 0.7149 |
| 词面特征重排 | 0.6728 | 0.6729 |

排除后的完整重排相对 RRF 差值为 **+0.02747**。这只是**后验描述性检查**：没有重新训练、没有重新选参，也没有替换主表的官方 300 条评估。它不能排除其余语义近重复，也不能审计冻结模型的预训练语料。

## 运行条件与验证

本次使用 Windows 11、Python 3.12.14、Intel Core i5-1130G7（4 核 8 线程）、16 GB 内存；ONNX Runtime 与 LightGBM 配置 2 个线程。设备同时运行其他应用，未隔离负载。

| 方法 | 查询耗时 p50 | 查询耗时 p95 |
| --- | ---: | ---: |
| BM25 | 2.00 ms | 3.38 ms |
| Dense | 15.08 ms | 25.41 ms |
| RRF | 15.88 ms | 32.56 ms |
| 完整重排 | 50.55 ms | 87.43 ms |
| 词面特征重排 | 48.55 ms | 88.60 ms |

这些是顺序执行、文档索引已加载时的函数级描述性耗时。Dense/RRF 包含查询编码；重排耗时为同一次 RRF 检索加特征计算和重排；不含模型下载、索引构建、HTTP 传输和并发排队。方法运行顺序固定，因此不能将它们当作受控服务压测，更不能换算为线上 QPS 或 SLA。

v1 交付时本地 **37 个测试通过**；加入 v2 后的当前测试状态见 [README](../README.md)。[GitHub Actions](https://github.com/chendi-Shi/evidenceforge-nlp/actions/workflows/ci.yml) 的 Linux Python 3.11/3.12 离线测试通过。[独立指标复核脚本](../scripts/verify_results.py) 从保存的 TREC 排名重算 5 种方法的 4 个指标及候选上限，均与报告一致。CI 验证代码行为，不自动重跑完整模型下载与基准实验。

科学文献检索相关性不等于支持关系；BEIR qrels 实际对应原始 cited 文档，具体核验见 [数据卡](DATA_CARD.md)。数据规模、未标注负例、长摘要截断与预训练暴露等限制见 [实验方法](METHODOLOGY.zh-CN.md)。
